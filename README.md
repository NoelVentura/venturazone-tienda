# Venture Zone - Tienda Online Hinode México

## 🏪 Descripción
Venture Zone es una tienda online especializada en productos Hinode México, ofreciendo una amplia gama de productos de salud, bienestar, perfumes, maquillaje y suplementos.

## 🌐 Sitio Web
- **URL del repositorio:** https://github.com/NoelVentura/venturazone-tienda
- **GitHub Pages:** https://noelventura.github.io/venturazone-tienda

## 📁 Estructura del Proyecto

### Páginas Principales
- `public/catalogo.html` - Catálogo principal de productos
- `public/pago.html` - Sistema de pago y checkout
- `public/documents/areaperfumes.html` - Catálogo de perfumes
- `public/documents/maquillaje.html` - Catálogo de maquillaje
- `public/documents/Cuidadocorporal.html` - Productos de cuidado corporal
- `public/documents/suplementos.html` - Suplementos nutricionales

### Carpetas de Assets
- `public/images/` - Imágenes de productos y recursos visuales
- `public/css/` - Estilos CSS personalizados
- `public/js/` - Scripts JavaScript
- `public/fonts/` - Fuentes tipográficas
- `public/videos/` - Videos promocionales

## 🛍️ Características

### Funcionalidades del E-commerce
- ✅ **Carrito de compras** con localStorage
- ✅ **Sistema de cantidades** para cada producto
- ✅ **Navegación por carrusel** automática y manual
- ✅ **Diseño responsive** para móviles y desktop
- ✅ **Chat de soporte** integrado con Botpress
- ✅ **Sincronización de carrito** entre pestañas

### Productos Disponibles
- 🧴 **Perfumes HND** - Fragancias masculinas y femeninas
- 💄 **Maquillaje** - Productos de belleza
- 🧴 **Cuidado Corporal** - Productos de higiene personal
- 💊 **Suplementos** - Nutrición y bienestar

## 🚀 Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos avanzados con animaciones
- **JavaScript ES6+** - Funcionalidad interactiva
- **GitHub Pages** - Hosting gratuito
- **Botpress** - Chat de soporte al cliente

## 🔧 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/NoelVentura/venturazone-tienda.git
   ```

2. **Navegar al directorio:**
   ```bash
   cd venturazone-tienda
   ```

3. **Abrir en navegador:**
   - Abrir `public/catalogo.html` en tu navegador
   - O usar un servidor local como Live Server
